# 조아라 · 백엔드 개발자

Java · Spring Boot와 TypeScript · NestJS로 B2B 플랫폼 백엔드를 개발합니다.
서버 초기 구축, 비동기 처리, 공공 · IoT 외부 연동을 맡아 왔고,
성능 · 안정성 · 외부 연동 문제를 깊이 다루는 개발자를 목표로 합니다.

## 주요 작업

회사 업무와 개인 프로젝트 코드는 비공개 저장소에 있어 여기에는 보이지 않습니다.

- **건물 에너지 · 탄소배출 플랫폼 백엔드** (2023.05 - 현재)
  서버 초기 구축, RabbitMQ 비동기 재계산, 공공 · IoT 외부 연동
- **온라인 교육 플랫폼 백엔드** (2022.05 - 2023.04)
  소셜 로그인 · 토큰 인증, 수강 신청 · 승인 워크플로, 단위 테스트 약 400건
- **Open Till Close** · 매장 오픈 · 마감 운영 관리 앱 (2026.07 - 현재, [open-till-close.com](https://open-till-close.com))
  RLS 정책 70개로 매장 단위 권한 설계, 실제 역할로 경계를 검증하는 DB 테스트를 CI에 연동
